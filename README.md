# 🛒 Amazon Clone

A modern Amazon-inspired e-commerce website built to replicate the core functionality and user experience of Amazon.
This project demonstrates responsive web design, dynamic product browsing, shopping cart functionality, and a clean, 
intuitive user interface.

## 🚀 Features

- 🏠 Responsive Home Page
- 🔍 Product Search
- 🛍️ Product Listing
- 📦 Product Details
- ➕ Add to Cart
- ❌ Remove from Cart
- 🛒 Shopping Cart
- 💳 Checkout Interface
- 👤 User Authentication (if implemented)
- ❤️ Wishlist (if implemented)
- 📱 Fully Responsive Design
- ⚡ Fast and Smooth User Experience etc

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- React
- Node
- MySQL
